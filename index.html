SDR → HDR 转换器 v0.7 · 本地处理，不上传

v0.7 更新：新增 PNG 输入（自动转 JPEG 底图；透明区域铺白、16-bit 降为 8-bit）

把普通 SDR JPG / PNG 转成带增益图（gain map）的 HDR JPG：HDR 屏上高光更亮、画面更通透； 普通屏 / 旧软件显示和原图完全一样。原图字节（含 EXIF/ICC）原样保留，全程在浏览器本地处理。

把 JPG / PNG 拖到这里，或点击选择文件 支持大图（4500 万像素级）；PNG 会自动转成 JPEG 底图（透明铺白）；增益图默认全分辨率，也可切半分辨率
高级参数：过渡曲线 / 细节尺度 / 通透感 / 人像保护 / 增益图分辨率
提示：导出的文件在不支持 HDR 的显示环境里和原图看起来一样，这是正常现象；只有 HDR 屏 + 支持的浏览器/相册才会显示更亮的高光。
  1. 先把文件用 AirDrop / 文件 App / 数据线传到手机或 HDR 电脑上；
  2. iPhone/iPad：存到「照片」或直接在 Safari 打开（iOS 18+ 支持 gain map HDR JPG）；
  3. Android：用 Chrome 或系统相册打开（Android 14+）；
  4. Windows：系统显示设置里打开 HDR，用 Chrome/Edge 打开；Mac：Safari 打开（XDR 屏）；
  5. 若某台设备看不到变化，把该设备的 系统版本 + 浏览器版本 记下来反馈。
